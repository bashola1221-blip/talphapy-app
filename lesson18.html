18. Dictionaries
Introduction: Key-Value Pairs

Think of a real-world dictionary. You look up a word (the key) to find its meaning (the value).

In Python, a Dictionary works the exact same way. It stores data in pairs: a Key and a Value. Instead of using index numbers (like Lists), you use the Key to get the Value.

Creating a Dictionary

We use curly braces { } to create a dictionary. Each pair is written as key: value.

student = {
"name": "Ada",
"age": 14,
"course": "Python"
}
print(student)

Accessing Values

To get a value, you put the key inside square brackets, just like a list index.

print(student["name"]) # Output: Ada
print(student["course"]) # Output: Python

🎯 Adding and Changing

You can add a new key-value pair or change an existing one by assigning a value to the key.

student["age"] = 15 # Changes age to 15
student["city"] = "Lagos" # Adds a new city key
print(student)

Looping through a Dictionary

You can loop through all the keys in a dictionary.

student = {"name": "Ada", "age": 14}
for key in student:
print(key, ":", student[key])

🎯 Quick Summary

• Dictionaries store Key: Value pairs.

• Use { } to create them.

• Access values using the key: dict["key"].

• You can add or change values easily.
