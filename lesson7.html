7. Lists
Introduction: Storing Multiple Things

So far, our variables could only hold one thing at a time (like one name or one age). But what if you want to store the names of 50 students in a class?

You could make 50 variables (student1, student2...), but that would be a nightmare. Instead, we use a List.

Think of a class register. It's one book (one list) that holds many names in a specific order.

Creating a List

Lists are wrapped in square brackets [ ], and the items inside are separated by commas.

fruits = ["apple", "banana", "cherry"]

To get a single item from the list, you use its index (its position number).

print(fruits[0]) # Output: apple

⚠️ Important: Computers start counting at 0, not 1. So the first item is at index 0, the second at index 1, etc.

Changing a List

Lists are mutable — meaning you can change them after you create them. Think of editing a register when a new student joins.

  • fruits.append("orange") — Adds "orange" to the end.
  • fruits.remove("banana") — Removes "banana".
  • fruits[0] = "mango" — Changes the first item to "mango".
fruits = ["apple", "banana"]
fruits.append("orange")
print(fruits)

How many items are inside?

If you want to know how many items are in a list, you use the len() function (short for length).

fruits = ["apple", "banana", "cherry"]
print(len(fruits)) # Output: 3

🎯 Looping through a List

The most powerful thing you can do with a list is go through every item one by one. This is like calling names from the register.

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
print(fruit)

Notice we didn't need range(). Python automatically visits every item in the list, one by one.

🎯 Quick Summary

• Lists store multiple values in one variable, wrapped in [ ].

• You access items using their index, starting at 0.

• Use append() to add, remove() to delete.

• Use len() to count the items.

• You can loop through a list using for item in list:.
