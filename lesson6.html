6. Loops
Introduction: Why Loops?

Imagine doing 100 push-ups. You don't do them in one single move. You do one, then repeat, then repeat... counting as you go.

A loop is Python's way of doing the same thing many times without making you write the same code 100 times.

Loops are the engine of programming. They are used in games (to keep the game running), in apps (to display a list of messages), and in AI (to train a model millions of times).

The `for` loop

A for loop repeats a block of code a specific number of times. We use the range() function to tell Python how many times to loop.

for i in range(5):
print("Hello")

range(5) means "give me the numbers 0, 1, 2, 3, 4" (5 numbers starting from 0).

Using the Loop Variable

Notice the i in the code above? That is a variable that holds the current number of the loop. You can print it to see which loop you are currently on.

for i in range(5):
print(i)

This will output: 0, 1, 2, 3, 4.

If you want to start at 1 instead of 0, use range(1, 6). (It stops right before the second number).

for i in range(1, 6):
print(i)

The `while` loop

for loops repeat a known number of times. A while loop repeats as long as a condition is True — like running laps until you are tired.

count = 1
while count <= 5:
print(count)
count = count + 1

Read it as: "While count is 5 or less, print it and add 1."

🎯 The Infinite Loop Warning

If you write a while loop and forget to update the variable (like count = count + 1), the condition will always be True, and the loop will run forever. Your program will freeze!

while x < 5:
print("This will run forever")
# Missing x = x + 1

If you run this in the playground, you will have to refresh the page to stop it!

🎯 Quick Summary

• for loops repeat a known number of times (using range()).

• while loops repeat as long as a condition is True.

• range(5) starts at 0 and stops before 5.

• Always make sure something inside a while loop changes the condition to avoid infinite loops!
