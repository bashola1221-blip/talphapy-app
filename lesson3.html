2. Variables & Data Types
Part 1: What is a variable?

Imagine a market stall with labelled containers. One jar says "rice", another says "beans". Each jar holds something.

A variable is exactly that: a labelled container in your program.

name = "Ada"
age = 14

name is the label. "Ada" is what's inside.

Different containers hold different things. Python has 4 main types:

1. String (text)
name = "Ada" — Always in quotes.

2. Integer (whole number)
age = 14 — No quotes, no decimal point.

3. Float (decimal)
price = 4.5 — Has a dot.

4. Boolean (True or False)
is_student = True — Only two values.

🎯 The naming rules:

✅ my_name = "Ada" (Valid)

❌ 2name = "Ada" (Can't start with a number)

❌ my name = "Ada" (No spaces allowed)
