3. Operators & Math
Introduction: Python as a Calculator

Python is incredibly powerful at math. You can use it like a regular calculator to add, subtract, multiply, and divide.

Why learn math operators?

Whether you are building a game (calculating health points), a business app (calculating profit), or an AI (calculating probabilities), you will use math operators every single day as a programmer.

In this lesson, we will cover the basic math symbols and the tricky ones that confuse most beginners.

The Basic Operators

You already know these from school, but Python uses slightly different symbols:

  • + Addition (5 + 3 = 8)
  • - Subtraction (10 - 4 = 6)
  • * Multiplication (4 * 3 = 12)
  • / Division (10 / 2 = 5.0)
print(5 + 3)
print(4 * 3)

Notice that division in Python (/) always gives a decimal result, even if it divides perfectly.

The Tricky Two: // and %

Imagine you have 7 oranges and 2 friends. You want to share them equally.

Floor Division (//) gives each friend the whole amount they can get:

print(7 // 2) # Output: 3

Modulo (%) gives you the remainder (what is left over):

print(7 % 2) # Output: 1

🎯 Order of Operations (BODMAS)

Python follows the exact same math rules you learned in school. Multiplication and division happen before addition and subtraction.

print(2 + 3 * 4)

Because 3 * 4 happens first (12), and then 2 + 12 = 14. Not 20!

If you want to add first, you must use brackets:

print((2 + 3) * 4)

🎯 Quick Summary

• + - * / are basic math operators.

• // gives the whole share, % gives the leftover.

• ** is used for powers (e.g., 2 ** 3 is 8).

• Python follows BODMAS (brackets, orders, division, multiplication, addition, subtraction).
