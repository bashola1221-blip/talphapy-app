1. Your First Python Program
Introduction: What is Python?

Before we write any code, let's talk about what Python actually is and why it's one of the best languages to learn.

What is Python?

Python is a popular programming language created by Guido van Rossum in 1991. It was designed to be easy to read and write, almost like plain English. Today, it is the fastest-growing programming language in the world.

What can you build with it?

  • Web Apps: Instagram and Spotify use Python.
  • Artificial Intelligence: ChatGPT and self-driving cars rely on Python.
  • Games: Many indie games are built with Python.
  • Automation: Bots that do boring tasks for you.

In this course, we will start from absolute zero. By the end, you will be writing real code.

Giving the Computer Instructions

Imagine you want to build a house. You can't just tell a builder "make me a house" — you have to give clear instructions, one step at a time.

A programming language works the same way. You give the computer clear instructions, one line at a time. Python is one of those languages.

Example:

print("Hello, world!")

That line tells the computer: show the words "Hello, world!" on the screen.

The print() Megaphone

Think of a market announcer with a megaphone. He shouts: "Fresh tomatoes!" — everyone hears it.

print() is Python's megaphone. Whatever you put inside it, Python shouts to the screen.

print("My name is Ada")
print("I am learning Python")

Each print() is a new shout on a new line.

🎯 The One Rule: Case Sensitivity

Python is case-sensitive, like your bank password. The computer treats uppercase and lowercase letters as completely different.

print("Hello") # This works ✅
Print("Hello") # This fails ❌

Same letters, but the capital P confuses Python.

🎯 Quick Summary

• Python is a powerful language used for apps, AI, and games.

• print() is used to display text on the screen.

• Text must always be wrapped in quotes ( " " ).

• Python is case-sensitive. print() is not the same as Print().
