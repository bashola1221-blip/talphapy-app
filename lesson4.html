4. Input & Output
Introduction: Talking to the Computer

So far, we have only been telling the computer what to do (Output). But to make interactive apps, games, and calculators, we need the computer to ask us questions and wait for our answers (Input).

Why is this important?

Every time you log into Instagram, type a message in WhatsApp, or search for a video on YouTube, you are providing input. In Python, we use a special function called input() to get information from the user.

The input() function

print() sends text to the screen. input() pauses the program and waits for the user to type something and press Enter.

name = input("What is your name? ")
print("Hello, " + name)

When you run this in the playground, a box will pop up asking for your name. Whatever you type gets stored in the variable name.

The Big Catch: input() is always text

This is the #1 mistake beginners make. No matter what the user types, Python treats it as a String (text).

age = input("Your age: ")
# If you type 14, age is now "14" (text), not 14 (number)
print(age + 1)

If you run this and type 14, it will crash! You can't add a number to text.

🎯 How to fix it: int()

To do math with user input, you must convert the text to a number using int() (for whole numbers) or float() (for decimals).

age = int(input("Your age: "))
print(age + 1)

Now, if you type 14, Python converts it to a real number, and prints 15.

Putting it together

You can also convert numbers back to text using str() if you want to join them with other words.

name = input("Your name: ")
age = int(input("Your age: "))
print("Hello " + name + "! Next year you will be " + str(age + 1))

🎯 Quick Summary

• input() asks the user for information.

• It always returns a String (text).

• Use int() to convert text to a whole number.

• Use str() to convert a number back to text for printing.
