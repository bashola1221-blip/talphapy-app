4. String Manipulation
Introduction: Working with Text

In Lesson 2, we learned that a String is just text wrapped in quotes. But Python gives us superpowers to change, combine, and analyze that text.

Whether you are building a chat app, a game, or a website, you will spend 80% of your time manipulating text. Let's learn how to do it.

Joining Strings (Concatenation)

You can stick two strings together using the plus + sign. Think of it like gluing two pieces of paper together.

first_name = "Ada"
last_name = "Okafor"
full_name = first_name + " " + last_name
print(full_name)

The Magic of f-strings

Using + to join variables and text can get messy. The modern, easiest way to mix text and variables is using an f-string.

Just put an f before the quotes, and put variables inside curly brackets { }.

name = "Ada"
age = 14
print(f"Hello, my name is {name} and I am {age} years old.")

Changing Case

You can easily change text to uppercase or lowercase using methods. A method is like a built-in tool attached to the string.

  • .upper() makes everything CAPITAL LETTERS.
  • .lower() makes everything lowercase letters.
message = "Hello World"
print(message.upper())
print(message.lower())

Counting & Replacing

Two more super useful tools:

  • len() counts how many characters (letters/spaces) are in a string.
  • .replace() swaps out a word for another word.
sentence = "I love Java"
print(len(sentence))
print(sentence.replace("Java", "Python"))

🎯 Quick Summary

• Use + or f-strings to join text.

• .upper() and .lower() change the case.

• len() counts the characters in a string.

• .replace() swaps words.
