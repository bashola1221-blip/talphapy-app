2. Variables & Data Types
Introduction: What is a Variable?

In Lesson 1, we learned how to print text to the screen. But what if we want to save that text and use it later? That's where variables come in.

The Market Stall Analogy

Imagine a market stall with labelled containers. One jar has a label that says "rice", another says "beans". Each jar holds something inside.

A variable is exactly that: a labelled container in your computer's memory. You give it a name, and you put a value inside.

Creating Your First Variable

In Python, you create a variable by choosing a name and using the equals sign (=) to assign a value to it.

name = "Ada"

name is the label. "Ada" is what's inside the jar.

If you type print(name) and run it, the computer will look inside the jar labelled "name" and print Ada.

The 4 Basic Data Types

Different jars hold different things. In Python, there are 4 main types of data you can put into a variable:

  • String (Text): Always in quotes. name = "Ada"
  • Integer (Whole Number): No quotes, no decimals. age = 14
  • Float (Decimal): A number with a dot. price = 4.5
  • Boolean (True/False): Only two possible values. is_student = True
name = "Ada"
age = 14
price = 4.5
is_student = True

🎯 The Naming Rules

You can name variables almost anything, but there are strict rules:

  • ✅ Valid: my_name = "Ada" (lowercase, underscores)
  • ❌ Invalid: 2name = "Ada" (cannot start with a number)
  • ❌ Invalid: my name = "Ada" (no spaces allowed)
  • ❌ Invalid: for = 5 (cannot use Python keywords)
my_name = "Ada"
2name = "Error"

The last example will show a SyntaxError because it breaks the rules.

🎯 Quick Summary

• Variables are labelled containers for storing data.

• You create them using the = sign.

• Strings are text (in quotes), Integers are whole numbers, Floats are decimals.

• Variable names cannot start with numbers or contain spaces.
