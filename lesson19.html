19. Project 3: Contact Book
Introduction: Build a Real App

You have learned variables, loops, functions, and dictionaries. Now, we are going to build a fully functional Contact Book.

You will be able to add a name and phone number, and then view all your saved contacts.

Step 1: The Empty Dictionary

First, we create an empty dictionary to store all the contacts. We will use the person's name as the key, and their phone number as the value.

contacts = {}

Step 2: Adding a Contact

Let's ask the user for a name and a number, and add it to the dictionary.

name = input("Enter name: ")
number = input("Enter number: ")
contacts[name] = number
print("Contact saved!")

Step 3: Viewing All Contacts

We can use a for loop to print every name and number in the dictionary.

for name in contacts:
print(name, "-", contacts[name])

Step 4: The Full App

Let's put it all together inside a while loop so the user can keep adding contacts until they decide to quit.

contacts = {}
while True:
print("1. Add Contact")
print("2. View Contacts")
print("3. Quit")
choice = input("Choose: ")
if choice == "1":
name = input("Name: ")
num = input("Number: ")
contacts[name] = num
elif choice == "2":
for n in contacts:
print(n, "-", contacts[n])
elif choice == "3":
break

• You used a while loop for the menu.
