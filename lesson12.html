12. While Loops
Introduction: Repeating Until...

In the last lesson, we learned the for loop, which repeats a known number of times (like exactly 5 times).

But what if you are guessing a password? You don't know how many tries it will take. You just keep trying while the password is wrong.

That is what a while loop does. It repeats as long as a condition is True.

The `while` loop

We use while followed by a condition. As long as the condition is True, the loop keeps running.

count = 1
while count <= 5:
print(count)
count = count + 1

Read it as: "While count is 5 or less, print it and add 1."

The Golden Rule

Look at the line count = count + 1. This is called updating the variable. If you forget this line, the loop will run forever because the condition will always be true.

while count <= 5:
print("This runs forever!")
# Missing count = count + 1

🎯 The `+=` Shortcut

Python allows you to write count = count + 1 as count += 1. They mean the exact same thing, but the shortcut is faster to type.

count = 1
while count <= 3:
print(count)
count += 1

While Loops with Input

This is where while loops shine. We can keep asking the user for a password until they get it right.

password = ""
while password != "1234":
password = input("Enter password: ")
print("Access Granted")

🎯 Quick Summary

• while loops repeat as long as a condition is True.

• Always update the variable inside the loop to avoid infinite loops.

• += is a shortcut for adding to a variable.
