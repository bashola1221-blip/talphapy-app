5. Conditionals
Part 1: if

Think of your car's fuel gauge. If the tank is low, you stop at a filling station. If it's fine, you keep driving.

That's what if does in Python — it checks a condition and decides what to do.

age = 15
if age >= 18:
print("You can vote")

Notice the colon : at the end of the if line. And the indent (4 spaces) on the line below. Both are required.

else and elif

if alone handles one case. Add else for the other:

if age >= 18:
print("You can vote")
else:
print("Too young to vote")

For more than two cases, use elif (short for "else if"):

if score >= 70:
print("A")
elif score >= 60:
print("B")
else:
print("C")

🎯 Comparison operators

== equal to
!= not equal to
> greater than
< less than
>= greater or equal
<= less or equal

⚠️ Watch out: = assigns, == compares.

x = 5 # sets x to 5
x == 5 # asks "is x equal to 5?"
