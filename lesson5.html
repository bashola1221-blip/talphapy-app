5. Conditionals
Introduction: Making Decisions

Think of your car's fuel gauge. If the tank is low, a light comes on. If it's fine, the light stays off. The car is making a decision based on a condition.

In Python, we use conditionals to tell the computer: "If this is true, do that. Otherwise, do something else."

This is how apps know to show a "Login" button if you aren't signed in, and a "Profile" button if you are.

The `if` statement

We use the if keyword to check a condition. If the condition is True, the indented code below it runs.

age = 15
if age >= 18:
print("You can vote")

⚠️ Notice the colon : at the end of the if line. And the 4 spaces (indentation) on the line below. Both are strictly required in Python!

Handling the alternative: `else`

What if the condition is False? We use else to catch everything that isn't True.

if age >= 18:
print("You can vote")
else:
print("Too young to vote")

More than two choices: `elif`

If you have multiple conditions to check, use elif (short for "else if"). Python checks them from top to bottom, and runs the first one that is True.

score = 75
if score >= 90:
print("A")
elif score >= 70:
print("B")
else:
print("C")

The Comparison Operators

To build conditions, you use these symbols:

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to

⚠️ The #1 Mistake: Do not confuse = (assigning a value) with == (checking if two things are equal).

x = 5 # Assigns 5 to x
x == 5 # Asks: is x equal to 5?

🎯 Quick Summary

• if checks a condition and runs code if True.

• else catches any case that isn't True.

• elif lets you check multiple conditions.

• Always end the line with a colon : and indent the next line.

• Use == to compare, and = to assign.
