13. Functions
Introduction: Reusable Code

Imagine you are building a house, and you need to hammer 1,000 nails. You could write the instructions for hammering a nail 1,000 times. Or, you could write the instructions once, give it a name (like "HammerNail"), and just say "HammerNail" 1,000 times.

In Python, a Function is a reusable block of code with a name. It saves you from writing the same code over and over.

Defining a Function

We use the def keyword (short for define) to create a function. Just like loops and if statements, it needs a colon and indentation.

def greet():
print("Hello, World!")

If you run this code, nothing happens. Defining a function just teaches the computer the instructions. It doesn't actually run them yet.

Calling a Function

To actually run the code inside the function, you have to call it by typing its name followed by parentheses.

def greet():
print("Hello, World!")

greet() # This runs the code!

Notice you can call it as many times as you want without rewriting the print() statement.

🎯 Parameters (Inputs)

A function is much more powerful if you can give it information. You do this by putting a variable name inside the parentheses. This is called a parameter.

def greet(name):
print("Hello, " + name)

greet("Ada")
greet("Bashir")

Return Values (Outputs)

Sometimes you don't want the function to print something. You want it to calculate a value and give it back to you so you can use it elsewhere.

We use the return keyword for this.

def add(a, b):
return a + b

result = add(5, 3)
print(result)

🎯 Quick Summary

• def is used to create a function.

• You must call the function to run it.

• Parameters are inputs you put inside the parentheses.

• return sends a value back to where the function was called.
