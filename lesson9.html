9. Conditionals (Part 2)
Introduction: Multiple Choices

In the last lesson, we learned how to make a choice between two things (if / else).

But what if you have more than two choices? Think of a school grading system: A, B, C, D, or F. That's five different possibilities!

To do this, we use the elif keyword (which stands for "else if").

The `elif` statement

elif allows you to check multiple conditions in order. Python checks them from top to bottom.

score = 75
if score >= 90:
print("A")
elif score >= 70:
print("B")
else:
print("C")

How Python reads it

Python reads the code from top to bottom. As soon as it finds a condition that is True, it runs that block and skips the rest.

For a score of 75:

  • Is 75 >= 90? No.
  • Is 75 >= 70? Yes! It prints "B" and ignores the rest.

🎯 Order Matters!

Because Python stops at the first True condition, you must write your elif statements in the correct order.

If you check `score >= 50` BEFORE `score >= 90`, a student with a 95 will get a "C" instead of an "A"! Always check the highest requirements first.

if score >= 90: ...
elif score >= 80: ...
elif score >= 70: ...
else: ...

Using `elif` with Input

Let's combine what we learned in Lesson 7. We can ask the user for their age and give them a specific ticket price.

age = int(input("How old are you? "))

if age < 5:
print("Free ticket")
elif age < 18:
print("Child ticket: ₦500")
else:
print("Adult ticket: ₦1000")

🎯 Quick Summary

• elif is used to check multiple conditions.

• Python checks from top to bottom.

• It runs the first True condition and skips the rest.

• Always order your elif statements from most specific (highest) to least specific.
