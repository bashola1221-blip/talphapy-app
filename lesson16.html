16. Intro to Lists
Introduction: Storing Multiple Items

So far, a variable can only hold one thing (like `age = 15`). But what if you want to store the names of 50 students in a class?

You could make 50 variables, but that's crazy. Instead, we use a List.

Think of a list as a shopping bag. It can hold multiple items in a specific order.

Creating a List

We create a list using square brackets [ ]. Inside, we put the items separated by commas.

fruits = ["apple", "banana", "cherry"]
print(fruits)

Indexing (Accessing items)

To get a specific item from the list, you use its index (position number) inside square brackets.

⚠️ Important: Computers start counting at 0, not 1!

fruits = ["apple", "banana", "cherry"]
print(fruits[0]) # Output: apple
print(fruits[1]) # Output: banana

🎯 Negative Indexing

Here is a cool trick. If you use a negative number, it counts from the end of the list. -1 is the last item, -2 is the second to last.

fruits = ["apple", "banana", "cherry"]
print(fruits[-1]) # Output: cherry

Mixed Data Types

A list can hold any data type, and it can even mix them! Strings, numbers, and booleans can all live in the same list.

student = ["Ada", 14, True]
print(student[0]) # Ada
print(student[1]) # 14

🎯 Quick Summary

• Lists hold multiple items in order.

• Use [ ] to create them.

• Indexing starts at 0.

• Negative indexing starts from the end.
