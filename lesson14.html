14. Modules & Random
Introduction: Borrowing Tools

Python comes with a massive toolbox. But you don't want to carry the whole toolbox with you every time you write code.

A Module is like a smaller, specific toolbox that you can borrow when you need it. For example, there is a module for math, a module for dates, and a module for generating random numbers.

In this lesson, we will learn how to use the random module to make our programs unpredictable.

The `import` keyword

To use a module, you have to import it at the very top of your code. This tells Python to go get that toolbox.

import random

Once you import it, you can use any tool inside the random toolbox by typing random. followed by the tool name.

Random Numbers

The most useful tool is random.randint(a, b). It picks a random whole number between a and b (including both ends).

import random

dice = random.randint(1, 6)
print(dice)

Run this code a few times. You will get a different number every time!

🎯 Random Choices

Another great tool is random.choice(). It picks a random item from a list of options.

import random

coin = random.choice(["Heads", "Tails"])
print(coin)

The Math Module

Python also has a built-in math module for complex calculations.

import math

print(math.sqrt(25)) # Square root
print(math.pi) # The value of PI

🎯 Quick Summary

• Modules are toolboxes of code you can borrow.

• Use import at the top of your file.

• random.randint() gives a random number in a range.

• random.choice() picks a random item from a list.
